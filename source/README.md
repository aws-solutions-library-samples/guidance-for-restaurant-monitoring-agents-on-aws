# Source Code

This folder contains the source code for the Restaurant Monitoring Agents guidance.

## Structure

- `lambda/` - Lambda function code and utilities
- `website/` - Frontend web application

## Lambda Functions

The Lambda functions provide:
- Restaurant monitoring agent workflows
- Equipment data processing
- Automated ticket creation
- API endpoints for the dashboard

## Website

The website provides:
- Interactive 3D dashboard
- Real-time equipment monitoring
- Agent chat interface
- User authentication
