# Kiro Session Template

Copy this at the start of each Kiro session:

```
Project: Restaurant Monitoring Agents on AWS
Context: See .kiro/project-context.md
Current Task: [from .kiro/current-task.md or specify new task]
Today's Focus: [specific deliverable]

Files in scope: [list 2-3 key files]

Question: [your specific question]
```

## Example Sessions

Project: Restaurant Monitoring Agents on AWS
