## Executive Summary

The guidance deploys a serverless stack (Amazon API Gateway, AWS Lambda, Amazon
DynamoDB, Amazon S3, Amazon CloudFront, Amazon Cognito, AWS WAF) fronting an
Amazon Bedrock AgentCore agent. Encryption, authentication, and edge protection
are configured by default.

**Overall posture:** Hardened baseline with two open hardening items (CORS
origin scope and API request rate limiting). See Section 6.

---

## 1. Authentication & Authorization

- **API Gateway** — All data and chat methods (`GET /restaurants`,
  `/equipment`, `/inventory`, `/staffing`, `/tickets`; `POST /chat`,
  `/chat-stream`) use `AuthorizationType: COGNITO_USER_POOLS` with a Cognito
  authorizer. `AuthorizationType: NONE` appears only on `OPTIONS` (CORS
  preflight) methods, which per the CORS specification cannot carry
  authorization headers.
- **Cognito password policy** — `MinimumLength: 12`, `RequireSymbols: true`,
  plus uppercase, lowercase, and numbers.
- **MFA** — `MfaConfiguration: OPTIONAL`. See open item in Section 6:
  organization policy requires MFA for all users.
- **IAM** — Lambda and agent execution roles are scoped to
  `${ProjectName}-*` DynamoDB tables and the `amazon.nova-*` Bedrock model
  family (least privilege).

## 2. Network & Edge Security

- **CloudFront** — HTTPS enforced; `MinimumProtocolVersion: TLSv1.2_2021`;
  Origin Access Control for S3.
- **AWS WAF** — WebACL attached with AWS managed rule groups.
- **Security headers** — HSTS, `X-Content-Type-Options`, `X-Frame-Options`.

## 3. Data Protection

- **DynamoDB** — Server-side encryption with a **customer managed KMS key**
  (`SSEType: KMS`, `KMSMasterKeyId` referencing a stack-owned `AWS::KMS::Key`)
  on all tables. Point-in-time recovery enabled. `DeletionPolicy: Retain` on
  data tables.
- **Lambda** — Dead-letter queue configured for asynchronous failure capture.
- **In transit** — All client traffic over HTTPS/TLS 1.2+.

## 4. Secrets & Configuration

- No account IDs, Cognito IDs, API URLs, or credentials are hardcoded in source.
  Frontend resource identifiers are injected into `frontend/config.js` at deploy
  time from CloudFormation outputs.
- Table names and model IDs are read from environment variables in
  `deployment/agent-code/agent.py` with convention-based defaults.
- The demo Cognito user password in `deployment/config.env` is a placeholder
  (`CHANGE_ME_BEFORE_DEPLOY`) that must be set before deployment.

## 5. Monitoring & Logging

- CloudFront access logging and Lambda CloudWatch Logs are enabled.
- **Recommended additions for production:** CloudTrail (multi-region), CloudWatch
  alarms (Lambda errors/throttles, API 4xx/5xx, DynamoDB throttling), and AWS
  Config for drift detection.

## 6. Open Items (Action Required Before Production)

### 🟡 Medium

1. **CORS allows any origin.** `Access-Control-Allow-Origin: '*'` is set in
   `restaurant-monitoring-base-template.yaml` and `chat-endpoint.yaml`.
   Organization policy requires restricting this to the CloudFront domain.
   **Fix:** replace `'*'` with the deployed CloudFront domain.

2. **No explicit API request rate limiting.** No API Gateway usage plan /
   method throttling or WAF rate-based rule is defined. **Fix:** add API Gateway
   stage throttling and/or a WAF `RateBasedStatement`.

3. **MFA is optional, not enforced.** Organization policy requires MFA for all
   Cognito users. **Fix:** move to required MFA (TOTP) or enforce via a Cognito
   Lambda trigger.

### 🟢 Low / Optional

4. Migrate to a CloudFront response headers policy that adds a Content Security
   Policy (CSP).
5. Consider VPC-bound Lambda with VPC endpoints if network isolation is
   required by your compliance regime.

## 7. Fixed / Not Applicable

- Hardcoded credentials, account IDs, and endpoints — removed from source
  (values injected at deploy time).
- Raw exception messages returned to callers — the chat Lambda now returns a
  generic `Internal server error` and logs details server-side only.
- KMS customer managed keys — implemented (was AWS-managed in earlier builds).
- Password policy (length 12 + symbols) — implemented.
